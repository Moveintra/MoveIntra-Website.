# MoveIntra Logistics

MoveIntra is India's leading logistics aggregator, simplifying shipping for growing businesses.

## Features

- **Smart Dashboard**: Manage everything from one place.
- **Real-Time Tracking**: Track your shipments with live updates.
- **Fast Delivery**: Partnering with top courier services.
- **Lowest Rates**: Competitive pricing for all your shipping needs.

## Tech Stack

- **Frontend**: HTML5, CSS3 (Custom & Bootstrap 5), JavaScript
- **Fonts**: Google Fonts (Outfit, Poppins)
- **Icons**: Font Awesome

## Setup

1. Clone or download the repository.
2. Open `index.html` in your web browser.
